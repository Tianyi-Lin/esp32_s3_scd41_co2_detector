## 倒装预览的已知问题

- SCD41 本体朝后盖外侧，传感器表面比后盖外表面内缩约 1 mm。
- 保持 ESP32 PCB 下表面到 CO₂ PCB 上表面约 20 mm；为此后盖外轮廓向外加深了 4.28 mm。前盖仍为 3 mm，后盖底板为 2 mm，整机总厚度约 36.53 mm。
- 用户已反馈整机前后显得过厚，需进一步评估布局和减薄方案。
- 模块两侧的接线插座目前仅以简化外形表示，**尚未计入实际插头、拔插操作和导线弯曲空间**。已有实体碰撞检查通过，不代表接线可装配性已验证。

## 如何手工编辑

使用 FreeCAD RC 打开对应零件的 `.FCStd` 文件，展开 `Body`，双击需要修改的 `Sketch` 或特征。各目录里的 `怎么编辑.txt`、`使用说明.txt` 和检查记录提供进一步说明。

- `.FCStd`：FreeCAD 工程；带草图/特征历史的独立零件适合手工改尺寸、孔位和特征。
- `.step` / `.stp`：交换实体几何，不能保留原始 FreeCAD 草图特征历史。
- `.stl`：打印用三角网格，不适合按原特征直接编辑。

本次仅归档所选模型文件夹；工作区中的 Python 模型生成脚本不在此目录中。尺寸单位均为 mm，打印前请结合实际电路板、插头和紧固件再次核对。
