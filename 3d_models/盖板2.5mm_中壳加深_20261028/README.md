# 当前候选版：前后盖 2.5 mm，新增深度由中间外壳承担

这是 2026-10-28 按最新要求修改的独立版本，原来的横置后盖和加深后盖预览均保留，不覆盖历史工程。

## 本次修改

- 前盖基础板厚 **2.5 mm**，后盖基础板厚 **2.5 mm**。
- **后盖没有外围加深围边**，外底面 Z=0，内侧大平面 Z=2.5；内部四个传感器安装支撑台保留。这些局部支撑台不属于板厚或外围围边。
- SCD41 保持长边平行外壳长边，安装孔距 X20 / Y18；传感器倒装朝外，表面低于后盖外表面约 **1 mm**。
- CO₂ PCB 安装面 Z=7.28，PCB 上表面 Z=8.48；ESP32 PCB 下表面 Z=28.48，两块 PCB 的垂直距离保持 **20 mm**。
- 新增高度由中间外壳承担；中层板、ESP32、Type-C 窗口和按钮同步上移 **4.28 mm**。侧脚钉、双层四角螺丝柱的 45°平面切削等结构保留。
- 相比横置、未倒装版本，中间件下配合面从 Z2.05 改为 Z2.55，上配合面上移 4.28 mm，所以中间件零件高度净增加 **3.78 mm**，变为约 **30.98 mm**。
- 前后盖四角通孔同轴，M2.5 沉孔直径仍为 **5.1 mm**。前盖沉孔深 1.35，后盖沉孔深 1.4。
- 减薄后重建了显示窗的上口过渡：下口仍为 **32.85×17.89、R2.5、中心 X=-1.5675**；上口改为同心等宽外扩的 **35.946×20.986、R4.048**，保留 R0.4 上缘过渡。没有改变显示区域的下口位置。此调整消除了旧偏心斜面在 STEP 转换和网格化时的问题。

整机前后外表面距离约 **36.03 mm**。本次主要统一盖板并转移加深结构，不代表已压缩 20 mm 接线空间。

- `装配检查_盖板2.5mm_中间壳加深.FCStd`：完整紧凑装配，包含两块电路板、SCD41 本体及两个简化插座。
- `上盖_2.5mm_草图编辑.FCStd`、`后盖_2.5mm_无围边_草图编辑.FCStd`、`中间外壳_加深_草图编辑.FCStd`：独立草图/特征工程。
- `打印文件/`：对应本版的三个 STL 和三个 STEP。不要混用旧文件夹里的后盖或中间件。
- `检查记录.json`：实体、STEP 读回、STL、孔位同轴及装配碰撞检查结果。
- 生成源码：`../scripts/redesign_uniform_covers.py`。在 FreeCAD Python 环境执行，默认使用所在仓库的模型目录，也支持 `--root`；输出到独立暂存目录，不覆盖输入工程。

## 检查边界

三个零件均为单一有效实体，独立工程保存后可重开、草图完全约束；STEP 读回通过扩展几何检查。三个 STL 均封闭、单连通，无非流形、无自交、无不一致三角面朝向。现有装配模型检查的部件之间无体积重叠。

**实际插头、拔插操作和导线弯曲空间仍未验证。** 两个插座仍是简化外形，现有模型无碰撞不等于实物接线已确认。本版是用于继续检查的候选版，打印前仍需结合插上线的传感器实物核对。
